Dashboard de vendas da Porsche

Projeto DIO - Digital Innovation One, em parceria com o Santander. 

1. Perguntas de negócio:
-> Quais os principais modelos de carro vendido por cidade
-> Qual modelo de carro mais saiu em um período
-> Quero insights de carros populares de vendas com base nos dados em cada cidade.
   
3. Prompt que gerou o dashboard:
Utilizando o recurso de Canvas, renderize uma dashboard em html ao lado.
#Filtros
-> Modelo da Porsche -> Model Year -> City ->Pay method Perguntas de negócios e kpis -> Quais os principais modelos de carro vendido por cidade -> Qual modelo de carro mais saiu em um período -> Quero insights de carros populares de vendas com base nos dados em cada cidade.
Sobre UI/UX se baseie no site oficial da Porsche Brasil: https://www.porsche.com/brazil/pt Tenha um ar elegante e refinado.

4. Mudanças no prompt: Inicialmente propús estado, posteriormente indiquei a filtragem por cidade, para ter um detalhamento maior das vendas.

5. Tratamentos da base antes de ir para a IA:
Criação de tabela dinâmica, com modelos e preços sanitizados. Além, de alteração nos campos numéricos, com a adição de soma dos campos selecionados.

6. Utilizei o ChatGPT com  Canvas.
